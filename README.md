# Kalavidara Balaga

## Problem Statement
Traditional artists often struggle to showcase their talent and connect with event organizers. 
Kalavidara Balaga is an Android application designed to help artists register their profiles, 
display their art forms, and allow users to search and contact artists easily.

---

## Project Description
Kalavidara Balaga is an Android application developed using Kotlin and Firebase. 
The application allows artists to create profiles with their personal details, 
skills, district information, and contact numbers.

Users can browse artist profiles, search based on district or art type, 
and directly contact artists for bookings and cultural events.

---

## Features
- User Authentication using Firebase
- Artist Registration
- Firestore Database Integration
- RecyclerView Artist Listing
- Search and Filter by Skill and District
- Booking System
- Direct Call Feature
- Edit and Delete Artist Profiles
- Splash Screen and Login System

---

## Tech Stack
- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Firestore
- XML Layouts
- RecyclerView

---

## Installation Steps

1. Clone the repository
git clone https://github.com/Sunithakulal/KalavidaraBalaga.git

2. Open the project in Android Studio

3. Connect Firebase using google-services.json

4. Sync Gradle files

5. Run the application on Emulator or Android device

---

## Run the Project
- Open Android Studio
- Click Run ▶
- Select Emulator or Physical Device
